## 1. Pengenalan

### Apa itu Warasa?

Warasa (Waralaba Santai) adalah platform AI-powered yang membantu penjual online menghasilkan konten produk berkualitas tinggi dalam hitungan menit. Dengan Warasa, Anda bisa:

- **Generate konten produk** (judul, deskripsi, keywords) menggunakan AI
- **Generate gambar produk** dengan 3 angle variations (front, three-quarter, side)
- **Export ke Shopee** dalam format Excel yang 100% sesuai template
- **Hitung biaya dan keuntungan** dengan ROAS Calculator dan Shopee Fee Calculator
- **Analisis kompetitor** untuk rekomendasi harga yang akurat

### Manfaat Menggunakan Warasa

1. **Hemat Waktu:** Dari 3-5 jam menjadi 30-45 menit untuk 50 produk
2. **Kualitas Konsisten:** AI-generated content dengan standar tinggi
3. **Mudah Digunakan:** Interface intuitif, tidak perlu pelatihan
4. **Gratis:** Platform 100% gratis untuk UMKM Indonesia
5. **Shopee-Ready:** Export langsung bisa diupload ke Shopee
6. **SEO-Friendly:** Konten yang dihasilkan optimized untuk search engine

### Siapa yang Harus Menggunakan Warasa?

- **UMKM Online** yang jual di Shopee, Tokopedia, Lazada
- **Dropshipper** yang perlu generate ratusan produk
- **Affiliate Marketer** yang promosi banyak produk
- **Digital Marketing Agency** yang kelola banyak toko

## 2. Memulai

### 2.1 Akses Aplikasi

**URL:** https://warasa.vercel.app

Buka browser (Chrome, Firefox, Safari, atau Edge) dan kunjungi URL di atas.

### 2.2 Registrasi

**Langkah-langkah:**

1. Buka https://warasa.vercel.app
2. Klik tombol **"Get Started"** di pojok kanan atas
3. Klik **"Register"** di bawah form login
4. Isi form registrasi:
   - **Nama Lengkap:** Masukkan nama Anda
   - **Email:** Masukkan email aktif
   - **Password:** Buat password (minimal 8 karakter)
   - **Konfirmasi Password:** Ulangi password
5. Klik **"Register"**
6. Anda akan langsung login ke dashboard

### 2.3 Login

**Cara 1: Login dengan Email**

1. Klik **"Login"** di pojok kanan atas
2. Masukkan **Email** dan **Password**
3. Klik **"Login"**

**Cara 2: Login dengan Google (Disarankan)**

1. Klik **"Login"** di pojok kanan atas
2. Klik tombol **"Login dengan Google"**
3. Pilih akun Google Anda
4. Anda akan langsung login ke dashboard

**Keunggulan Login dengan Google:**
- Tidak perlu ingat password
- Lebih cepat (1 klik)
- Lebih aman (2FA dari Google)

### 2.4 Requirement Perangkat

- **Browser:** Chrome, Firefox, Safari, Edge (versi terbaru)
- **Internet:** Minimal 1 Mbps
- **Screen:** Minimal 1024x768 (desktop recommended)
- **JavaScript:** Harus diaktifkan
- **Cookies:** Harus diaktifkan

## 4. Manajemen Project

Project adalah wadah untuk mengelompokkan produk Anda. Misalnya: "Toko Fashion", "Produk Elektronik", dll.

### 4.1 Membuat Project Baru

**Langkah-langkah:**

1. Dari dashboard, klik menu **"Projects"** di sidebar
2. Klik tombol **"Create New Project"**
3. Isi form:
   - **Nama Project:** Contoh: "Toko Fashion Saya"
   - **Deskripsi:** (Opsional) Deskripsi project
4. Klik **"Create"**

### 4.2 Melihat Daftar Project

Setelah membuat project, Anda akan melihat daftar project:

**Informasi yang Ditampilkan:**
- Nama project
- Deskripsi
- Jumlah produk di dalamnya
- Tanggal dibuat
- Status (Active/Archived)

**Aksi yang Tersedia:**
- **View:** Klik nama project untuk melihat produk di dalamnya
- **Edit:** Klik icon edit untuk mengubah nama/deskripsi
- **Archive:** Klik icon archive untuk menyembunyikan project
- **Delete:** Klik icon trash untuk menghapus project

### 4.3 Archive dan Restore Project

**Untuk Archive Project:**
1. Di list project, klik icon **archive** (icon kotak)
2. Project akan disembunyikan dari list utama

**Untuk Restore Project:**
1. Klik **"Show Archived"** di atas list
2. Klik icon **restore** pada project yang ingin di-restore
3. Project akan muncul kembali di list utama

**Mengapa Archive?**
- Menyembunyikan project yang tidak aktif
- Tidak menghapus data
- Bisa di-restore kapan saja

## 5. Product Generator

Ini adalah **fitur utama** Warasa. Anda bisa generate konten produk (title, description, keywords, images) menggunakan AI.

### 5.1 Quick Generator

Quick Generator adalah cara tercepat untuk generate produk. Cukup masukkan nama produk, dan AI akan generate semua konten.

**Langkah-langkah:**

1. Dari dashboard, klik **"Quick Generator"** atau navigasi ke **Product Generator > Quick Generator**

2. **Isi Form:**
   - **Product Name:** Masukkan nama produk
     - Contoh: "Kaos Polos Katun Premium"
     - Contoh: "Sepatu Sneakers Casual Pria"
     - Contoh: "Tas Ransel Laptop 15 inch"
   
   - **Select Project:** Pilih project tempat produk akan disimpan
   
   - **Generate Options:** Checklist apa yang ingin di-generate:
     - ☑ Generate Title (Judul SEO-friendly)
     - ☑ Generate Description (Deskripsi 150+ kata)
     - ☑ Generate Keywords (5-10 keywords)
     - ☑ Generate Images (3 angle variations)

3. Klik tombol **"Generate Product"**

4. **Tunggu 10-15 detik** untuk AI processing

5. **Review Hasil:**
   - Judul yang di-generate
   - Deskripsi produk
   - Keywords
   - 3 gambar (front, three-quarter, side)
   - SEO Score (0-100)

6. **Edit jika diperlukan** (optional)

7. Klik **"Save Product"**

### 5.2 Smart Generator

Smart Generator adalah versi lebih advanced dengan analisis kompetitor untuk rekomendasi harga dan kategori yang lebih akurat.

**Langkah-langkah:**

1. Navigasi ke **Product Generator > Smart Generator**

2. **Isi Form Lengkap:**
   - **Product Name:** Nama produk
   - **Category:** Pilih kategori dari dropdown
   - **Price:** Harga produk (opsional)
   - **Stock:** Jumlah stok
   - **Weight:** Berat produk (gram)
   - **Description:** Deskripsi singkat (opsional)

3. **Upload CSV Kompetitor** (Opsional):
   - Format CSV: `nama_produk, harga, terjual, lokasi`
   - Contoh:
     ```
     Kaos Polos Premium, 85000, 1250, Jakarta
     Kaos Katun Distro, 75000, 890, Bandung
     ```

4. Klik **"Generate with Smart Analysis"**

5. **Review Hasil:**
   - Konten yang di-generate (title, desc, keywords)
   - **Rekomendasi Harga** berdasarkan kompetitor
   - **Rekomendasi Kategori**
   - **Top Keywords** dari kompetitor
   - **Market Insights**

6. Klik **"Save Product"**

### Tips untuk Hasil Terbaik

1. **Nama Produk Spesifik:** 
   - ❌ "Baju" (terlalu umum)
   - ✅ "Kaos Polos Katun Premium Pria" (spesifik)

2. **Gunakan Smart Generator untuk:**
   - Produk baru yang belum ada di market
   - Ingin tahu harga kompetitif
   - Ingin analisis kompetitor

3. **Gunakan Quick Generator untuk:**
   - Produk yang sudah familiar
   - Generate cepat dalam jumlah banyak
   - Sudah tahu harga dan kategori

## 7. Export ke Shopee

Fitur ini memungkinkan Anda export produk ke format Excel yang 100% sesuai template Shopee mass upload.

### 7.1 Persiapan Sebelum Export

Pastikan produk Anda memiliki:
- ✅ Nama produk
- ✅ Deskripsi
- ✅ Harga
- ✅ Stok
- ✅ Berat
- ✅ Minimal 1 gambar
- ✅ Kategori

### 7.2 Melakukan Export

**Langkah-langkah:**

1. Navigasi ke menu **"Export"** di sidebar

2. **Pilih Produk:**
   - Checklist produk yang ingin diekspor
   - Atau klik **"Select All"** untuk pilih semua

3. Klik **"Export to Shopee"**

4. **Proses Export:**
   - Validasi data (cek kelengkapan)
   - Upload gambar ke storage
   - Generate public URLs
   - Format Excel sesuai template Shopee

5. **Preview 5 Baris Pertama:**
   - Cek apakah format sudah benar
   - Pastikan URL gambar terlihat

6. Klik **"Download Excel"**

7. File .xlsx akan terdownload

8. **Upload ke Shopee:**
   - Buka Shopee Seller Centre
   - Pilih **"Upload Massal"**
   - Upload file Excel yang baru didownload
   - Selesai!

### 7.3 Tips Export

1. **Pastikan Data Lengkap:**
   - Semua produk harus ada nama, harga, stok
   - Minimal 1 gambar per produk
   - Kategori sudah dipilih

2. **Preview Sebelum Download:**
   - Cek 5 baris preview
   - Pastikan URL gambar terlihat
   - Pastikan format sesuai

3. **Batch Export:**
   - Bisa export multiple produk sekaligus
   - Recommended: 10-50 produk per export
   - Untuk >100 produk, lakukan dalam batch

4. **Jika Ada Error:**
   - Cek notifikasi error
   - Pastikan semua field terisi
   - Cek format gambar (JPG, PNG, WEBP)
   - Maksimal 10MB per gambar

## 8. Kalkulator ROAS

ROAS (Return on Ad Spend) Calculator membantu Anda mengukur efektivitas iklan Anda.

### 8.1 Cara Menggunakan ROAS Calculator

**Langkah-langkah:**

1. Navigasi ke menu **"Calculators" > "ROAS Calculator"**

2. **Masukkan Data:**
   - **Ad Spend:** Total biaya iklan
     - Contoh: 500.000 (Rp 500 ribu)
   
   - **Revenue:** Total pendapatan dari iklan
     - Contoh: 2.000.000 (Rp 2 juta)
   
   - **Product Cost:** (Opsional) Biaya produksi
     - Contoh: 800.000
   
   - **Marketplace Fee:** (Opsional) Biaya marketplace
     - Contoh: 100.000
   
   - **Target ACOS:** (Opsional) Target Advertising Cost of Sales
     - Contoh: 25 (25%)

3. Klik **"Calculate"**

4. **Lihat Hasil:**
   - **ROAS:** 4.0 (Revenue / Ad Spend)
   - **ACOS:** 25% (Ad Spend / Revenue)
   - **Profit Margin:** Persentase laba bersih
   - **Recommendation:** Saran optimasi iklan

### 8.2 Interpretasi Hasil

**ROAS (Return on Ad Spend):**
- **ROAS > 5:** Excellent - Sangat profitable
- **ROAS 3-5:** Good - Profitable
- **ROAS 2-3:** Average - Perlu optimasi
- **ROAS < 2:** Poor - Perlu perbaikan

**ACOS (Advertising Cost of Sales):**
- **ACOS < 20%:** Excellent
- **ACOS 20-30%:** Good
- **ACOS 30-40%:** Average
- **ACOS > 40%:** Perlu perbaikan

## 9. Kalkulator Biaya Shopee

Kalkulator ini membantu Anda menghitung biaya jual, komisi Shopee, dan estimasi laba bersih.

### 9.1 Cara Menggunakan Shopee Fee Calculator

**Langkah-langkah:**

1. Navigasi ke menu **"Calculators" > "Shopee Fee Calculator"**

2. **Masukkan Data:**
   - **Harga Jual:** Harga yang akan dijual
     - Contoh: 100.000 (Rp 100 ribu)
   
   - **Kategori:** Pilih kategori produk
     - Fashion, Elektronik, Kecantikan, dll
   
   - **Biaya Produksi:** (Opsional) Biaya membuat produk
     - Contoh: 50.000

3. Klik **"Calculate"**

4. **Lihat Breakdown:**
   - Harga Jual: Rp 100.000
   - Komisi Shopee: Rp 2.000 (2%)
   - Biaya Transaksi: Rp 1.500
   - Total Biaya: Rp 3.500
   - Estimasi Penerimaan: Rp 96.500
   - Estimasi Laba: Rp 46.500

5. **Gunakan Slider** untuk adjust harga dan lihat perubahan laba

### 9.2 Tips Menggunakan Kalkulator

1. **Hitung Harga Jual Optimal:**
   - Masukkan biaya produksi
   - Lihat estimasi laba
   - Adjust harga dengan slider
   - Cari harga yang memberikan laba maksimal

2. **Bandingkan Kategori:**
   - Coba kategori yang berbeda
   - Lihat perbedaan komisi
   - Pilih kategori yang paling menguntungkan

3. **Planning Produk Baru:**
   - Sebelum buat produk, hitung dulu
   - Pastikan harga kompetitif
   - Pastikan margin laba cukup

## 12. Troubleshooting

### Masalah 1: Tidak Bisa Login dengan Google

**Gejala:** Klik "Login dengan Google" tapi tidak redirect

**Solusi:**
1. Pastikan cookies dan JavaScript diaktifkan
2. Clear cache browser (Ctrl+Shift+Delete)
3. Coba browser lain (Chrome/Firefox)
4. Jika masih error, gunakan login dengan email

### Masalah 2: AI Generation Timeout

**Gejala:** Loading terlalu lama (>30 detik), eventually error

**Solusi:**
1. Tunggu 30 detik dan refresh halaman
2. Coba generate lagi (mungkin API sedang sibuk)
3. Jika masih error, hubungi admin
4. Pastikan API key Gemini masih aktif

### Masalah 3: Gambar Tidak Muncul

**Gejala:** Gambar yang sudah di-generate tidak tampil

**Solusi:**
1. Check internet connection
2. Clear cache browser
3. Hard refresh (Ctrl+Shift+R)
4. Jika masih tidak muncul, re-generate gambar

### Masalah 4: Export Excel Corrupt

**Gejala:** File Excel tidak bisa dibuka

**Solusi:**
1. Kurangi jumlah produk yang diekspor (maksimal 50 per sekali)
2. Pastikan semua produk memiliki data lengkap
3. Pastikan semua produk memiliki minimal 1 gambar
4. Coba download lagi

### Masalah 5: ROAS/Shopee Fee Calculator Hasil Tidak Akurat

**Gejala:** Hasil kalkulator tidak sesuai perhitungan manual

**Solusi:**
1. Pastikan semua input diisi dengan benar
2. Cek konfigurasi biaya Shopee (hubungi admin jika perlu)
3. Refresh halaman dan coba lagi
4. Jika masih error, laporkan ke admin

### Masalah 6: Upload Gambar Gagal

**Gejala:** Tidak bisa upload gambar, error message

**Solusi:**
1. Cek format file (hanya JPG, PNG, WEBP)
2. Cek ukuran file (maksimal 10MB)
3. Compress gambar jika terlalu besar
4. Coba upload satu per satu (bukan batch)

### Masalah 7: Produk Tidak Muncul di List

**Gejala:** Sudah buat produk tapi tidak muncul di product list

**Solusi:**
1. Cek filter - mungkin produk di-filter
2. Cek search - mungkin ada keyword yang match
3. Cek apakah produk di-archive
4. Refresh halaman (F5)

### Masalah 8: Loading Lambat

**Gejala:** Website loading sangat lambat

**Solusi:**
1. Check internet connection
2. Clear cache browser
3. Tutup tab browser yang tidak perlu
4. Coba browser lain
5. Jika masih lambat, mungkin server sedang sibuk

## Tips dan Trik

### 1. Generate Produk dalam Batch

Untuk generate banyak produk sekaligus:
1. Siapkan file CSV dengan nama produk
2. Gunakan Smart Generator
3. Upload CSV
4. AI akan generate semua produk dalam sekali proses

### 2. Gunakan Project untuk Organisasi

- Buat project per kategori: "Fashion", "Elektronik", "Aksesoris"
- Assign setiap produk ke project yang sesuai
- Mudah untuk manage dan export per kategori

### 3. Optimalkan SEO Score

Untuk dapat SEO Score tinggi:
- Title: 50-60 karakter
- Description: 150-160 kata
- Keywords: 5-10 keywords
- Gunakan kata kunci yang relevan

**SEO Score Factors:**
- Title length (25 poin)
- Description length (25 poin)
- Keyword density (25 poin)
- Image alt text (15 poin)
- Category relevance (10 poin)

### 4. Hemat Waktu dengan Quick Generator

Untuk produk yang sudah familiar:
- Gunakan Quick Generator (lebih cepat)
- Generate title, description, keywords, images sekaligus
- Edit hanya yang perlu diubah

### 5. Export secara Berkala

- Export produk setiap hari
- Jangan menunggu 100 produk baru
- Export 10-20 produk per hari lebih mudah

### 6. Manfaatkan Competitor Analysis

Gunakan Smart Generator dengan CSV kompetitor untuk:
- Mengetahui harga pasar
- Melihat keywords yang trending
- Memahami preferensi customer
- Menyesuaikan strategi pricing
